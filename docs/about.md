# 关于本站
## 写在前面
尊重是做人的底线，原则是立世的根基，人可以没有梦想，但不可以没有立场。

## 写笔记的初衷
做为技术路上的菜鸡，很高兴大佬们能来到我的小破站参观，本站主要目的为记录所见、所学、所得，在学习的路上，都会碰到一些不会的问题，就会去百度，有很多大佬文章的内容给了我很大的帮助，所以我也想通过笔记把自己会的一些知识记录下来，希望有一天可以帮助其他的人，就如同我之前那样。

## 写笔记的好处

### 一、系统的总结知识点
有时候你会这些东西，但可能自己不能成系统的讲出来，通过写笔记的方式可以把你会的东西系统的写出来，而且里面可能有一些细节，你之前都没注意到，这时候你又会学习到新的知识，帮助自己巩固一遍自己的所学，所以在写笔记的过程中也可以不断的提高自己。

### 二、错误指正
有的时候可能自己的观点是错误的，但是自己不知道，通过笔记写出来，会有各个平台的大佬们来阅读指正，这样可以对自己理解的东西更加的透彻清晰。

### 三、附带的成就感
分享自己的知识，并且有人阅读，有人喜欢/关注等，这是一件超级有成就感的事情，在这过程中也会逐渐提升自己的影响力（虽然并没有什么实际的影响）。
