# 关于本站
## 写在前面
尊重是做人的底线，原则是立世的根基，人可以没有梦想，但不可以没有立场。

## 写笔记的初衷
作为技术路上的普通学习者，很高兴大佬们的到访，搭建这个站点主要是为记录日常所见、所学与所得，学习过程中难免遇到难题，也曾依靠网上各路大佬的分享获得诸多帮助，因此我也希望以笔记的形式整理自己掌握的知识，在复盘沉淀的同时，也能像曾经被帮助的自己一样，为他人提供一点参考。

## 写笔记的好处

### 一、系统的总结知识点
有时候很多知识看似掌握，却无法有条理地复述出来，写笔记的过程中能把零散的内容梳理成体系，还能发现以往忽略的细节，在复盘之余巩固所学，实现自我提升。

### 二、错误指正
个人理解难免存在疏漏与误区，通过笔记写出来将内容公开分享后，也期待各位同好、前辈阅读指正，帮助我把知识理解得更加透彻。

### 三、收获分享的成就感
把知识分享出去，被阅读、被认可，本身就是一件很有成就感的事，也在这个过程中，慢慢收获同好的关注与交流（虽然目前并没有）。
